# landing-resume

Одностраничный сайт-визитка Валерии Семенюк — no-code веб-дизайнер.

## Стек

Чистые HTML / CSS / JS. Без сборки, без зависимостей — просто статические файлы.

```
index.html      разметка (hero · сейчас · бэкграунд · контакты)
styles.css      стили, палитра в CSS-переменных вверху файла
script.js       появление блоков при скролле (уважает prefers-reduced-motion)
assets/
  valeriya.jpg  портрет для первого экрана
```

## Как запустить локально

Достаточно открыть `index.html` двойным кликом в браузере.

## Деплой

Vercel, импорт из GitHub. Framework Preset — **Other**, build command и output
directory оставить пустыми: сайт отдаётся как статика.

## Что ещё заменить
